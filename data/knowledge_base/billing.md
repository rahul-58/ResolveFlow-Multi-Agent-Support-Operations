# Billing and duplicate charges

## Duplicate card charges

When a customer reports two charges for one order, first determine whether one
charge is still pending. A pending authorization can disappear without a refund
action. If both charges are settled, create a billing investigation task.

Support agents must not promise that a refund has been issued before the billing
team confirms the transaction. Ask only for safe references such as the order
number and the last four digits of the card. Never request a full card number,
CVV, password, or authentication code.
